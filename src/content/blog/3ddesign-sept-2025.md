#### This class will introduce you to the basics of 3D Design for 3D Printing.

![CTH Logo](/hack.png)


#### 3D Modeling for Absolute Beginners using Fusion 360
Location: CT Hackerspace, 30 Echo Lake Rd, Watertown CT

The class will provide an introduction to 3D Modeling using Fusion 360 software. The software is free to use for personal use. The curriculum is tailored for Absolute Beginners with no knowledge of or very little experience with 3D Modeling. In addition to learning basic 3D Modeling techniques, there will also be some emphasis on the thought-process of product design. 
 
In the class you will learn how to design simple and practical objects. These objects will be able to be 3D Printed on any consumer 3D Printer.

The class will be about 2 hours long. 

#### Class Requirements:

- 15 years old and up.
- Bring a Mac or PC Laptop.
- Install Autodesk Fusion 360 prior to the class! (the personal license is free)
  - https://www.autodesk.com/products/fusion-360/personal
  - or Google “Autodesk Fusion for personal use”
- Create an Autodesk Fusion account and make sure you can log into the software prior to the class!
- 3-Button Mouse with scroll wheel is recommended.
